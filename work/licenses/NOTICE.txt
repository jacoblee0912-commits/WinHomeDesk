0.2.1 additions: H.264 worker with input pumping on the transport owner thread; Windows Media Foundation hardware AVC420 encoder with CPU fallback, high-resolution result waits, stream-change and parameter-set handling. Uses Windows mf/mfplat/mfuuid/strmiids/ole32/oleaut32 system APIs. No Windows system DLLs are redistributed.

0.2.5: configurable right Alt to Hangul mapping independent of foreground layout, diagnostic traces; backward-compatible storage/credentials.
0.2.3 additions: 44.1kHz PCM capture/packet/negotiation compatibility, actual Microsoft playback regression; 10ms PCM chunks, WASAPI buffer/poll tuning, full-width Wave2 capture timestamps, duplicate-aware audio confirmation diagnostics.

0.2.6: application-account NLA/CredSSP/NTLMv2 plus legacy TLS. Uses Windows CNG MD4 only for protocol-required NT key derivation. RDCoreSdk/RDCMan proprietary binaries are NOT included.

0.2.7: disable unimplemented server UDP multitransport capability; match RDCMan 3.22 Shortpath configuration in tests. Retains application-account NLA/CredSSP/NTLMv2 plus legacy TLS. Uses Windows CNG MD4 only for protocol-required NT key derivation. RDCoreSdk/RDCMan proprietary binaries are NOT included.

0.2.8: integrated process-local RDCMan 3.22 IME startup hook, embedded in WinHomeDesk.exe. The custom hook is Apache-2.0. Original RDCMan binaries are not redistributed or modified. Server binaries identical to 0.2.7.

0.2.9: opt-in highest-privilege interactive logon task, current-user UAC registration helper, transactional startup migration. Native server and IME module unchanged.
