# 설계 및 제약

WinForms GUI가 전용 엔진 프로세스를 실행합니다. 엔진은 수정한 FreeRDP Windows shadow 구현을 바탕으로 로그인한 데스크톱을 캡처하고 RDP 클라이언트에 전달합니다.

화면은 DXGI 또는 GDI로 가져오며 최신 화면을 우선하는 대기 구조를 사용합니다. H.264 AVC420은 Windows Media Foundation GPU 인코딩을 우선 시도하고 실패하면 CPU로 전환합니다. AVC444·Planar·비트맵은 별도 CPU 경로입니다. 표시되는 계측은 서버의 단계별 비용이며 종단 간 화면 표시 지연을 직접 측정하지 않습니다.

오디오는 WASAPI loopback으로 시스템 소리를 가져와 RDP 오디오 채널로 전송합니다. 입력은 Windows 입력 주입 경로를 사용하므로 앱 실행 권한과 보안 데스크톱의 영향을 받습니다.

RDCMan 3.22 한글 보정은 접속하는 PC의 RDCMan 실행 시 자체 .NET 시작 모듈을 적용합니다. 서버만 바꿔 모든 클라이언트의 조합창을 없애는 기능은 아닙니다. 원본 RDCMan 바이너리를 수정하거나 배포하지 않습니다.

관리자 자동 실행은 현재 사용자 로그인 트리거와 InteractiveToken/HighestAvailable 작업을 사용합니다. 앱이 작업 등록 도구를 UAC로 실행하며 다른 관리자 계정 SID는 거절합니다. Windows 암호를 저장하거나 SYSTEM 서비스로 실행하지 않습니다.

## 인증 및 보관

- 접속 계정은 surface와 앱 전용 암호입니다. Windows 로그인 비밀번호가 아닙니다.
- 전용 인증 자료는 엔진 실행을 위해 프로세스 환경으로 전달합니다. 로그·RDP·RDG에 기록하지 않습니다.
- 자동 서버 시작용 암호는 현재 Windows 사용자 범위로 암호화해 저장합니다.
- RDP·RDG 생성 시 평문 접속 암호를 내보내지 않습니다.
- 설정과 인증서는 사용자 LocalAppData에 저장되며 이 저장소에 포함하지 않습니다.

## 범위

로그인 전, 잠금, UAC 보안 화면 및 절전 상태는 지원하지 않습니다. 현재 사용자의 화면을 공유하며 독립 다중 Windows 세션을 제공하지 않습니다. 네트워크 경로는 구현된 TCP를 사용하고 UDP multitransport는 광고하지 않습니다. VPN 출구 고정 IP가 곧 접속 가능한 인바운드 주소라는 뜻은 아닙니다.
